# Portfólio Front-End

Portfólio pessoal desenvolvido como projeto prático durante minha transição de QA para Engenharia de Software Front-End. A interface foi construída com base em um exercício de reprodução de layout do Figma.

## Status

A estrutura visual está implementada. O projeto ainda está em desenvolvimento: faltam a revisão final de responsividade e os próximos passos de JavaScript.

## Tecnologias

- HTML
- CSS

## O que foi praticado

- Estruturação semântica com HTML
- Estilização com CSS
- Layouts com Grid e Flexbox
- Tipografia, cores e espaçamentos a partir de uma referência do Figma
- Adaptação inicial para diferentes larguras de tela
- Organização dos estilos por seção
- Estados de foco visíveis para links

## Próximos passos

- Revisar o layout em telas pequenas, intermediárias e grandes
- Implementar interações com JavaScript
- Avançar nos fundamentos de JavaScript, incluindo funções, arrays, objetos, eventos, módulos, Promises e `async/await`
- Estudar TypeScript e React
- Explorar Next.js, integração com APIs e testes automatizados

## Como executar

Abra o arquivo `index.html` em um navegador.

## Observações

Este projeto é uma atividade de aprendizado. Antes de publicá-lo, vou revisar o conteúdo de exemplo e os dados de contato.
